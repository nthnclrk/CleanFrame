# Browser evidence

`compat-dock-720.png` and `compat-list-720.png` were captured by the browser regression suite on 27 October 2026, at 1280 × 720, before Light/Dark and the bundled wallpapers were removed. They use the fonts, wallpaper and icons of that time with a synthetic installed-app catalogue. The suite also checks 1920 × 1080 geometry.

These are desktop Chromium screenshots, not TV captures or proof of Chromium 85 compositing. They show readable labels and the rounded utility focus in the candidate UI. The wallpaper and icon sources/licences remain in the existing asset records and [third-party notices](../../THIRD_PARTY_NOTICES.md).

Historical: the `inputs-*-720.png` frames show the retired Settings → Samsung → Inputs screen at 1280 × 720 using the then-public fonts and three synthetic source records. They document browser layout, not a physical TV input or CEC result.

`home-defaults-public.png` and `home-espn-public.png` show this personal fork’s Live TV and ESPN Home entries at 1920 × 1080, captured on 15 November 2026 with the then-bundled public fonts (the app now uses the TV's system font). The background is the generated two-colour test JPEG, not owner artwork. They document Chromium layout only; tuner selection, native launches, installed icon appearance and Art Mode sync still need physical verification.
